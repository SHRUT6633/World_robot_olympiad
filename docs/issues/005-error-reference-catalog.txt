WRO 2026 Error Reference Catalog
=================================
Every error that can occur, when it happens, what causes it, and how the
code handles it.  Use this to debug on competition day.

======================================================================
I2C BUS ERRORS
======================================================================

Error           : OSError: [Errno 121] Remote I/O error
When            : Any I2C read/write (MPU6050, QMC5883L, VL53L0X, VL53L1X)
Cause           : I2C slave did not acknowledge its address.
                  Usually means the sensor is:
                  - Not powered (check VCC/GND)
                  - Wrong I2C address (check address jumper or code)
                  - Bus not initialised (run i2cdetect -y 1)
Where           : pi/sensors/imu/mpu6050.py  → _read_word()
                  pi/sensors/magnetometer/qmc5883l.py → read_raw()
                  pi/sensors/tof/vl53l0x.py → read_raw()
                  pi/sensors/tof/vl53l1x.py → read_raw()
Handling        : Exception caught → self._log_error() logs once per 2s
                  → after 50 failures, _enabled = False (auto-disable)
Logged as       : WARNING (rate-limited)
Severity        : HIGH if all sensors fail (I2C bus dead)
                  LOW if one sensor fails (hardware issue)

======================================================================
I2C BUS ERRORS (Input/Output)

Error           : OSError: [Errno 5] Input/output error
When            : I2C block read/write (QMC5883L, VL53L0X, VL53L1X)
Cause           : I2C bus communication failure.
                  - Bus contention (multiple masters)
                  - Bad wiring (SDA/SCL swapped, too long)
                  - Pull-up resistors missing (need 4.7k on SDA/SCL)
Where           : Same as Errno 121 locations
Handling        : Same as Errno 121
Logged as       : WARNING (rate-limited)
Severity        : HIGH

======================================================================
CAMERA ERRORS

Error           : cv2.error: ... CAP_IMAGES: can't find starting number
When            : Camera init or read
Cause           : Camera not connected or wrong device index.
                  - /dev/video0 doesn't exist
                  - Camera cable loose
                  - Camera not enabled (raspi-config)
Where           : pi/sensors/camera/camera_driver.py → init() / read()
Handling        : Returns None frame → perception tasks produce no
                  detections → robot continues with ToF/IMU only
Logged as       : ERROR (once at init)
Severity        : HIGH (no vision = no pillar detection)

======================================================================
CAMERA FRAME DROP

Error           : Camera read returned None
When            : Every sensor_task() tick (100 Hz)
Cause           : Camera buffer underrun or timeout.
                  - FPS too high for resolution
                  - CPU overloaded (perception + fusion + control)
Where           : pi/sensors/camera/camera_driver.py → read()
Handling        : Returns None → fusion_task uses last frame
                  → health monitor may flag "sensors" as dead
Logged as       : WARNING (rate-limited)
Severity        : MEDIUM (temporary glitch)
                  HIGH (persistent → restart)

======================================================================
UART / COMMS ERRORS

Error           : serial.serialutil.SerialException: device reports
                  readiness to read but returned no data
When            : UART read/write
Cause           : ESP32 not powered or wrong baud rate.
                  - /dev/serial0 doesn't exist
                  - ESP32 not flashed with correct firmware
                  - Baud mismatch (115200 vs 9600)
Where           : pi/comm/uart.py → read() / write()
Handling        : Returns None → no motor commands sent
                  → watchdog on ESP32 stops motors after 500ms
Logged as       : ERROR
Severity        : CRITICAL (robot cannot move)

======================================================================
UKF FILTER ERRORS

Error           : np.linalg.LinAlgError: Singular matrix
When            : UKF update() — covariance matrix inversion fails
Cause           : Measurements are all zero or identical.
                  - All sensors disabled/returning 0
                  - Filter not initialised with valid P matrix
Where           : pi/fusion/ukf.py → update()
Handling        : Exception caught → skip update, use prediction only
                  → state uncertainty grows until sensor recovers
Logged as       : ERROR
Severity        : MEDIUM (pose drifts until sensor recovers)

======================================================================
FILTERPY IMPORT ERROR

Error           : ImportError: cannot import name
                  'MerkedScaledSigmaPoints' from 'filterpy.kalman'
When            : Module import
Cause           : Typo in class name. Correct name is
                  MerweScaledSigmaPoints (not Merked).
Where           : pi/fusion/ukf.py → import line
Handling        : Program crashes on import — must be fixed before run
Logged as       : N/A (crash)
Severity        : CRITICAL (fix: use correct spelling)

======================================================================
LOGGER NOT INITIALISED

Error           : AttributeError: 'Logger' object has no attribute
                  'logger'
When            : First log.info() / .warn() / .error() call
Cause           : log.init() was never called before any log message.
                  The Logger singleton has no self.logger.
Where           : pi/system/logger.py → info(), warn(), error()
Handling        : CRASH — program terminates
                  Fixed by calling log.init() after import in main.py
Logged as       : N/A (crash)
Severity        : CRITICAL (fix: add log.init() in entry point)

SCHEDULER TASK TIMEOUT (fixed in v2)

Error           : Task never returns → Ctrl+C cannot stop robot
When            : scheduler.spin_once() awaits a callback
Cause           : Callback has while True loop and never returns.
                  scheduler._running flag never checked.
Where           : pi/system/scheduler.py → spin_once() → await callback
                  pi/main.py → all task callbacks (original)
Handling        : Fixed: removed while True from all callbacks.
                  Scheduler now controls rate via hz parameter.
Logged as       : N/A (livelock, not crash)
Severity        : CRITICAL (fixed — no longer occurs)

======================================================================
PILLAR NOT DETECTED

Error           : No pillars detected in camera frame
When            : perception_task (50 Hz)
Cause           : Pillar is outside camera FOV, lighting changed, or
                  colour thresholds are wrong for venue lighting.
Where           : pi/perception/pillar_detector.py → detect()
Handling        : Robot continues with ToF wall-following.
                  → If pillar never seen, passes wrong side → round ends
Logged as       : WARNING (rate-limited)
Severity        : HIGH (fix: adjust colour_thresholds in config)

======================================================================
PILLAR PASSED WRONG SIDE

Error           : Round stopped (judge decision)
When            : Vehicle crosses the radius line on the wrong side
                  of a pillar (Rule 9.19 / Appendix A section 5)
Cause           : Wrong pillar_logic in config (NORMAL vs REVERSED)
                  or pillar not detected in time.
Where           : N/A (judge decision, not code crash)
Handling        : Round ends with current score.
                  Next round: fix config or adjust thresholds.
Logged as       : N/A (competition rule)
Severity        : CRITICAL (change pillar_logic in surprise_rules.yaml)

======================================================================
PARKING FAILURE

Error           : Robot not fully inside parking zone or not parallel
When            : End of Obstacle Challenge (3 laps complete)
Cause           : Wrong steering mode for parking.
                  - Use OPPOSITE_PHASE for tight manoeuvres
                  - Use CRAB_WALK for sideways adjustment
Where           : pi/mission/state_machine.py → PARK state
Handling        : Partial points if partly parked (7 pts instead of 15)
Logged as       : INFO
Severity        : MEDIUM (still get partial points)

======================================================================
VEHICLE CHECK FAILURE (Competition Day)

Error           : Judge: vehicle exceeds size/weight limits
When            : Vehicle check before each round
Cause           : Vehicle > 300x200x300mm or > 1.5 kg (Rules 11.1-2)
Where           : Physical vehicle, not code
Handling        : 3 minutes to fix; disqualification if not fixed
Severity        : CRITICAL (measure and weigh before competition)
