# L298N Motor Driver Module

Drives the single AWD motor. One channel used (ENA + IN1 + IN2).

## Key electrical specs

| Parameter | Value |
|-----------|-------|
| VS (motor supply) | 5–35V (module: 5–12V recommended) |
| VS (our robot) | 7.4V battery rail, direct |
| Output current | 2 A per channel max |
| Dropout voltage | ~1.5–2V at 1 A (L298N is a linear H-bridge) |
| Onboard 5V regulator | 78M05 — WEAK (~50–100 mA). Do NOT power logic from it |
| Logic inputs | 5V compatible (driven by 3.3V ESP32 — OK, threshold ~2.3V) |
| PWM | ENA pin, up to 25 kHz |

## Power rail connection

- `VS` + `GND` → motor rail (battery direct, via fuse).
- Output OUT1/OUT2 → drive motor.
- NEVER use the module's onboard 5V output for the Pi, ESP32, or
  sensors — it cannot supply their current.

## Interface

- ENA = GPIO11 (PWM), IN1 = GPIO8, IN2 = GPIO9 (direction), ESP32.

## Protection notes

- Motor transients are absorbed by the 1000µF bulk cap on the motor
  rail — without it the ESP32 brownout-reset (v2.x, 4 days).
- Add a freewheeling diode across the motor if the module lacks one.
