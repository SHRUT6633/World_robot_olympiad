# QMC5883L Magnetometer

Absolute heading reference — fused with the IMU gyro to stop drift.

## Key electrical specs

| Parameter | Value |
|-----------|-------|
| Supply voltage | 2.16–3.6V (we run 3.3V) |
| Current | ~1 mA |
| Interface | I2C, address 0x0D |
| Field range | ±8 Gauss |
| Max ODR | 200 Hz |
| Logic level | 3.3V |

## Power rail connection

- Pi GPIO 3.3V pin (sensor rail).

## Interface

- SDA = Pi GPIO 2, SCL = Pi GPIO 3 (shared I2C-1 bus).

## Protection notes

- MOST sensitive part on the robot: motor current wires anywhere
  nearby corrupt the heading (v5.x incident, 3 days). Motor wires are
  kept away from this sensor and I2C is twisted with ground return.
