# MPU6050 IMU

Heading/attitude estimation for the fusion stack (UKF + complementary
filter).

## Key electrical specs

| Parameter | Value |
|-----------|-------|
| Supply voltage | 2.4–3.5V (we run 3.3V) |
| Current | ~3.9 mA |
| Interface | I2C (400 kHz), address 0x68 |
| Gyro full scale | ±250 / ±500 / ±1000 / ±2000 °/s |
| Accel full scale | ±2 / ±4 / ±8 / ±16 g |
| Sample rate | up to 1 kHz |
| Logic level | 3.3V |

## Power rail connection

- Pi GPIO 3.3V pin (sensor rail). Total sensor current < 60 mA —
  well inside the Pi 3.3V pin budget.

## Interface

- SDA = Pi GPIO 2, SCL = Pi GPIO 3 (shared I2C-1 bus with mag + ToFs).

## Protection notes

- I2C lines must be twisted with a ground return (magnetometer
  corruption incident, v5.x).
- Keep away from motor power wires.
