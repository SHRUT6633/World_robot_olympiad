# MG995 Steering Servo

One servo steers all four wheels through the 4WS mechanical linkage
(Rule 11.3 — single steering actuator).

## Key electrical specs

| Parameter | Value |
|-----------|-------|
| Supply voltage | 4.8–7.2V (we run 5V via UBEC) |
| Idle current | ~10 mA |
| Moving current | 250–450 mA |
| Stall current | up to ~1.5 A (datasheet up to 2.5 A) |
| Stall torque | ~9.4 kg·cm @ 4.8V, ~13 kg·cm @ 6V |
| Speed | 0.16 s/60° @ 4.8V |
| Signal | 50 Hz PWM, 0.5–2.5 ms pulse (1.0–2.0 ms typical) |

## Power rail connection

- Dedicated **isolated UBEC 5V / 3A** rail — it must never share a
  rail with the Pi/ESP32 (stall current sags shared rails → resets).

## Interface

- Signal = ESP32 GPIO13 (servo_pwm.c, 50 Hz).

## Protection notes

- Never power from the Pi 3.3V or the L298N's weak 5V output.
- Hard steering spikes are covered by the 100µF + 0.1µF caps on the
  servo rail.
